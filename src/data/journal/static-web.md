This week was mostly about the absolute basics, so things like how GitHub works and what HTML and CSS actually do. We have not really touched JavaScript yet.

We also had to make a breakdown sketch of our product. The original assignment was to make a small profile card with some information about yourself, but I pretty quickly realised I would probably be done with that in about ten minutes. So instead I started turning it into an actual website that introduces me.

The website you are on right now, actually. I hope you like it xoxo

But let us circle back to the breakdown sketch, because that is something I struggled with more than I expected.

The idea is basically to take a design and start breaking it apart before you build it. You draw boxes around the different pieces of content, decide which HTML elements make sense and then look at how everything needs to be grouped together.

Especially because by that point I was not working with a small profile card anymore. I had already started thinking about a much bigger website with multiple sections and a lot more structure.

It was a good reminder that knowing roughly how you want to build something and being able to explain that structure clearly are not always the same thing.
